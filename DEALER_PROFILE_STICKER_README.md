# Dealer Profile Sticker Generator

## Overview

The Dealer Profile Sticker Generator allows dealers to create custom QR code stickers that customers can scan to access their dealership profile and interact with the D.A.I.V.E AI assistant.

## Features

### 🎨 **Sticker Design**
- **DEALERIQ Branding**: Features the iconic DEALERIQ logo with car icon
- **D.A.I.V.E Integration**: Promotes the AI-powered customer assistance
- **Custom Stock Numbers**: Each sticker can have a unique stock number
- **Professional Layout**: Clean, modern design suitable for business use

### 📱 **QR Code Functionality**
- **Profile Access**: QR codes link directly to dealer profiles
- **AI Assistant**: Customers can access D.A.I.V.E for vehicle inquiries
- **Mobile Optimized**: Works seamlessly on all mobile devices

### 🖨️ **Export Options**
- **Download PNG**: High-quality sticker images for digital use
- **Print Ready**: Optimized for printing on various sticker materials
- **Multiple Sizes**: Different template sizes for various use cases

## How to Use

### 1. **Access the Sticker Generator**
- Navigate to your Dealer Profile page
- Look for the "Profile Sticker Generator" section
- Click "Generate Profile Sticker"

### 2. **Configure Your Sticker**
- **Select Template**: Choose from Classic, Minimal, or Premium designs
- **Enter Stock Number**: Add a unique identifier (e.g., 2691)
- **Preview**: See how your sticker will look

### 3. **Generate QR Code**
- Click "Generate QR Code" to create the QR code
- The system will generate a unique URL for your profile

### 4. **Download or Print**
- **Download**: Save as PNG for digital use
- **Print**: Print directly for physical stickers
